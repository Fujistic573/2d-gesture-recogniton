# Разпознаване на 2D форми с k-NN

**Ученик:** Николай Светославов Стефанов, № 20
**Избран вариант:** Вариант А

## Какво прави проектът?

Проектът разпознава прости ръчно нарисувани форми по координатите на точките, записани с мишката. Координатите се нормализират до 32 точки, а претеглен k-NN класификатор избира най-близките примери чрез симетрично Chamfer разстояние. Приложението показва топ 3 предположения, позволява записване на нови шаблони и включва мини-игра тип Skribbl. Обучаващата база включва разнообразни варианти за пеперуда, облак и корона.

## Как се стартира програмата?

Нужни са Python 3 и NumPy. Tkinter трябва да е наличен в инсталацията на Python.

```bash
pip install -r requirements.txt
python app.py
```

За повторно генериране на синтетичната база (текущата база вече е включена):

```bash
python generate_dataset.py
```

## Съдържание на хранилището

- `app.py` – графичен интерфейс и режими за разпознаване, игра и запис на примери
- `preprocessing.py` – нормализиране на входните щрихи до фиксиран брой точки
- `knn_classifier.py` – претеглен k-NN класификатор и работа с базата
- `generate_dataset.py` – генериране на синтетични примери
- `data/dataset.json` – шаблони за обучение (42 класа; 1914 примера, включително разширени класове за пеперуда, облак и корона)
- `data/scores.json` – запазен рекорд от мини-играта
- `requirements.txt` – нужни Python библиотеки
- `output/Pismena_Teoria.pdf` – писмена теория и анализ за защитата

## Изпълнение и оценка

Проектът е локално настолно приложение. За обективна оценка на модела трябва да се използва отделен набор от рисунъци, които не участват в базата, и да се изчисли точността (дял верни предсказания). Процентът, показван от интерфейса, е относителен дял на претеглените гласове на съседите, а не измерена точност.
